AGRO DZ — MISE A JOUR DES PHOTOS POUR GITHUB PAGES
==================================================

Ce ZIP corrige les photos manquantes du site :
https://mohandiberraken452-hue.github.io/Fruits-et-l-gumes/

Il contient 12 photographies illustratives integrees DIRECTEMENT dans app.js.
Aucun dossier assets/ a televerser : tous les fichiers sont a la racine.

POUR METTRE A JOUR LE DEPOT EXISTANT :
1. Decompresser ce ZIP sur votre ordinateur.
2. Ouvrir https://github.com/mohandiberraken452-hue/Fruits-et-l-gumes
3. Cliquer Add file > Upload files.
4. Selectionner TOUS les fichiers extraits (pas le ZIP lui-meme).
5. Si GitHub signale un conflit de nom, confirmer le remplacement des fichiers.
6. Cliquer Commit changes.
7. Attendre que GitHub Pages termine la publication, puis ouvrir :
   https://mohandiberraken452-hue.github.io/Fruits-et-l-gumes/#accueil
8. Si les anciennes images persistent, actualiser avec Ctrl+F5.

PHOTOS INTEGREES :
- Tomates, pommes de terre, oranges, pommes, carottes, fraises,
  poivrons, dattes Deglet Nour
- Pommes sechees, mangues sechees, tomates sechees,
  melange de legumes deshydrates

DEMONSTRATION UNIQUEMENT : prix et producteurs fictifs ; commandes et
ajouts de produits enregistres dans le navigateur, non transmis a un serveur.
